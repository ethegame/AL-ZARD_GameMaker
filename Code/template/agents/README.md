## 부르는 법 (메인 = AL-ZARD_GameMaker 오른쪽 터미널의 Claude)
- Agent 도구, subagent_type = general-purpose. 프롬프트 첫 줄: "`<팀 문서 폴더>/agents/<파일>` 을 Read 하고 그 정의대로 일한다." + 과제·범위.
- `<팀 문서 폴더>`·`<게임 폴더>`·`<Godot>` = 이 프로젝트의 팀 문서·게임 폴더·Godot 실행 파일 절대 경로 (메인 context 의 {TeamDocs}·{GameDir}·{GodotExe}) — 서브에이전트 프롬프트에 실제 경로로 적어 넘긴다.
- 작은 일(한두 줄 수정·질문 답)은 부르지 않고 메인이 직접. 서로 독립인 일(예: 경제 시뮬 비교 ∥ QA 회귀)은 한 번에 병렬로.
- 🏷️ 태그는 그 일의 팀으로 (현황판 불).
- **보고 대조**: 서브에이전트 보고의 "바꾼 파일"을 실제 수정 시각·내용과 대조한 뒤 사장님께 결과를 말한다.
