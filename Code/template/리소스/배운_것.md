# 리소스팀 배운 것

> 이 프로젝트를 하며 리소스팀이 직접 겪고 배운 것. 일이 끝날 때마다 배운 게 있으면 한 줄씩 아래에 더한다.
> 형식: `- 날짜 · 배운 것 · 근거(무슨 일에서, 숫자·파일이 있으면 같이) · 확신 상/중/하`
> 같은 교훈이 이미 있으면 새 줄 대신 그 줄에 근거를 더한다. 틀린 줄은 지우지 말고 앞에 "틀림:" 과 이유를 붙인다.
> 팀 정의(`agents/`)의 원칙과 부딪치면 **여기가 이긴다** — 이 게임에서 실제로 겪은 것이라서. 사장님이 좋다고 한 줄은 다음 판 팀 정의로 올릴 후보다.
