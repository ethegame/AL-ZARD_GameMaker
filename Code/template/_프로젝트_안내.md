## 흐름
1. 기획: `기획/게임컨셉.md` → 데이터 표, `리소스/필요그래픽_목록.md` 채우기

{web}2. 리소스: 목록을 보고 그림 도구로 생성 → 결과 파일과 상태 기록 (그림 도구가 없으면 canvas 기본 도형·무료(CC0) 에셋으로 대신)
3. 프로그래밍: `프로그래밍/개발_계획.md` 의 시스템 구현, 데이터·그래픽 연결

5. 버그·밸런스 결과를 기획에 반영하고 반복
