# AL-ZARD_GameMaker

게임을 만드는 Windows 데스크톱 앱이에요. 오른쪽에 Claude 가 있고, 기획 · 프로그래밍 · 리소스 · QA 네 팀 칸에서 Claude 와 말로 게임을 만들어요. 엔진은 Godot 또는 웹(HTML5+JS) 중에서 골라요.

## 설치
이 저장소의 **Releases** 에서 최신 `AL-ZARD_GAMEMAKER-Setup-<버전>.exe` 를 받아 더블클릭해요 ("Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행).
- 필요한 것(.NET 9 데스크톱 런타임 · WebView2)은 설치할 때 같이 깔려요.
- Claude Code 가 없으면 앱 오른쪽 칸이 설치 · 로그인 방법을 알려 줘요.

## 업데이트
새 판이 나오면 오른쪽 아래 [새 소식] 위에 **⬆ 업데이트** 버튼이 떠요. 누르면 받아서 설치하고 다시 켜져요. 만든 프로젝트 · 게임 · 설정은 그대로예요.

## 폴더
- `Code/` 앱 소스
- 내 프로젝트 · 게임 = 문서\AL-ZARD_GAMEMAKER
